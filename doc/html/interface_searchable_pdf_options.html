◆ customPageWidth

- (float) customPageWidth
readwritenonatomicassign

Output page width in points (1 pt = 1/72 inch), or 0 to not specify one. Set together with customPageHeight to choose the page outright, which takes precedence over enableAutoPageSize. The image is scaled to fit inside the page without cropping. Only takes effect when the input is an image file. For example A4 is 595.28 x 841.89.

◆ enableAutoPageSize

- (BOOL) enableAutoPageSize
readwritenonatomicassign

Whether to size the output page from the image's own resolution, matching it to the nearest standard paper. Only takes effect when the input is an image file; when NO, one image pixel becomes one page point. Defaults to NO.

◆ tableRecognitionAccuracy

- (TableRecognitionAccuracy) tableRecognitionAccuracy
readwritenonatomicassign

Table recognition accuracy. Defaults to TableRecognitionAccuracyBalanced, which works with the base documentai.model; TableRecognitionAccuracyHighAccuracy requires the table_legacy.model package. If the model of the requested accuracy is not loaded, the conversion still succeeds, but tables are recognized with the rule-based method instead, so the result differs.
