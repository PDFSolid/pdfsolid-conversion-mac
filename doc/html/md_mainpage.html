PDFSolid Conversion Objective-C SDK (macOS)

PDFSolid Conversion SDK 1.3.0 provides high-fidelity PDF and Word conversion for macOS Objective-C applications via PDFSolid.framework.

Capabilities

  • Convert PDF to Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV (.csv), HTML (.html), RTF (.rtf), Image, Plain Text (.txt), JSON (.json), and Markdown (.md).
  • Convert PDF to Searchable PDF and OFD with bundled DocumentAI support.
  • Convert Word (.docx) to PDF with optional heading/Word bookmarks, page ranges, and unsupported-feature diagnostics.

Framework Usage

Import <PDFSolid/PDFSolid.h>, verify your PDFSolid license with [LibraryManager licenseVerify:], initialize resources with [LibraryManager initialize:], and invoke CPDFConversion conversion methods.
